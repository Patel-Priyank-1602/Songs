# 🎵 MyTunes – Priyank Patel Vocal Sessions 🎶

A sleek, aesthetic, Spotify-inspired web music player exclusively showcasing the vocal recordings and studio covers sung by **Priyank Patel**.

---

## ✨ Features

- 🎧 **Exclusively Priyank's Vocals**: Every track is personally sung and recorded by Priyank Patel (Hindi classics, soulful indie, sufi rock, and English ballads). No ads, no third-party filler.
- 📱 **100% Mobile Responsive (Pixel-Matched to Mobile UI)**:
  - **Screen 1 (Mobile Home)**: Dynamic greeting, sunset featured banner, horizontal scrolling **Your Mixes** cards, and clean vertical **Recently Played** song rows with instant play buttons.
  - **Screen 2 (Mobile Search & Browse All)**: Dedicated search tab with live instant keyword search, colorful 2-column **Browse All** category cards (*Hindi Classics*, *Acoustic Hits*, *Soulful & Indie*, *English Ballads*, *Romantic*, *Chill Vibes*), and a **Trending Now** list.
  - **Screen 3 (Full-Screen Mobile Player Sheet)**: Slides up smoothly from the persistent floating mini-player. Displays giant album art, live scrubber, shuffle, prev/next, huge play/pause button, audio device and queue triggers, and an expandable **Lyrics & Vocal Notes** drawer.
- 📜 **Dedicated Playlist & Song List View**:
  - Clicking any playlist in the sidebar (*Chill Vibes*, *Hindi Romantics*, *Acoustic Hits*, *English Ballads*, *Liked Songs*) opens a complete Spotify-style track table with numbers, animated equalizer wave bars, thumbnails, mood badges, timestamps, and like buttons.
  - Quick `← Back to Overview` navigation.
- 🔍 **Real-Time Instant Search**: Live search across track titles, tags, moods, languages, and lyrics with highlighted search matches.
- 🎼 **Expandable Lyrics & Recording Notes**: View the real lyrics and singer notes for each track directly in the player sheet.
- ❤️ **Liked Songs Persistence**: Favorite any track to curate your personal *Liked Songs* collection stored in `localStorage`.
- ⌨️ **Keyboard Shortcuts (Desktop)**:
  - `Space`: Play / Pause
  - `→`: Next Track / +5s Seek
  - `←`: Previous Track / -5s Seek
  - `M`: Mute / Unmute
  - `S`: Toggle Shuffle
  - `R`: Toggle Repeat Mode (Off / All / Single)
  - `L`: Like / Unlike Current Track
  - `Esc`: Close Modals / Player Sheets & Return to Home
